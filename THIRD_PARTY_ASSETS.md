# Third-party product assets

The seeded product catalogue uses photographs downloaded from Unsplash. Each file is mapped to exactly one seed product in `database/schema.sql`; the same source information is also stored in the `ProductAsset` table.

All listed photographs are used under the [Unsplash License](https://unsplash.com/license). This inventory is kept with the repository so product imagery remains traceable when catalogue data changes.
